# AdMob Specification

## Status: not applicable to the core product

This is a premium corporate virtual-office experience, not an
ad-supported mobile game. Do not add AdMob to the MVP.

If a separate mobile app/monetization requirement is approved later,
record business purpose, platform SDK support, privacy/legal review,
non-deceptive placement rules, test ads and release validation. Do not
load ad SDKs or transmit visitor data to ad networks without explicit
approval.
