# Scraping Specification

## Status: not required for the MVP

The virtual office needs no scraping pipeline. Do not implement one
because this template exists.

If later authorized, document exact sources, business purpose,
terms/robots review, legal/privacy/copyright assessment, rate limits,
caching, attribution, update schedule, validation, provenance and
deletion.

Never bypass authentication, CAPTCHAs, paywalls or technical controls;
harvest credentials/personal data; or publish scraped content without
rights and verification.
