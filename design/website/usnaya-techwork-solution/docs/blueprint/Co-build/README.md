# Co-build Protocol

1.  Read master rules, PRD, TRD, architecture and microtasks.
2.  Inspect repository before edits.
3.  Execute one phase at a time.
4.  Before a large change, list planned files and purpose.
5.  Implement the smallest end-to-end increment.
6.  Run actual checks; inspect diff.
7.  Update microtask status, changelog and decisions.
8.  Stop and report blockers instead of silently changing architecture.

Every phase report must include summary, changed files, tests and actual
results, acceptance criteria met/not met, risks, and next task.
