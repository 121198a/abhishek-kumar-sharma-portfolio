# Phase 1 --- Audit and Foundation

Audit the repo and working tree. Confirm framework, package manager,
scripts, deployment and existing UI/API/state patterns. Do not
overwrite.

Create/verify a 3D canvas using the existing stack, a basic blockout
scene, camera, lighting, loading/error fallback and one approved local
asset if available. If none exists, use clearly labelled primitive
geometry. Add tests for new pure logic.

Acceptance: existing app still works; desktop browser renders a 3D
scene; loading/error UI works; actual available checks/build run; no
secrets or fake final assets. Update tracker/changelog and stop for
report.
