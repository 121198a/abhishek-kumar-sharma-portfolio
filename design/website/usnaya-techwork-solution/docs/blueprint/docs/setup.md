# Setup Guide

## Existing repository

Inspect tree, package manifest/lockfile, framework, routes, UI, API
clients, environment variables, tests, deployment and git status. Use
the actual package manager and scripts. Do not overwrite working code.

## New project only

If confirmed to be new: create React + TypeScript + Vite, add only
required 3D/state libraries, establish the canvas and loading/error
shell, load a test scene, verify build, then follow `15_MICROTASKS.md`.

Never invent test scripts or report checks that were not run.
