# USNAYA Techworks Solution 3D Project --- 3D Office Blueprint

Documentation and phase prompts for a desktop-first interactive 3D
corporate office.

## Start here

1.  Read `00_MASTER_RULES.md`.
2.  Read PRD, TRD and architecture.
3.  Review `15_MICROTASKS.md`.
4.  Give your coding agent `prompts/00_PROJECT_BOOTSTRAP_PROMPT.md`.
5.  Execute one phase prompt at a time; do not paste all phases at once.

This is a documentation/prompt pack, not a completed app. A week is a
target for a tested vertical-slice MVP if foundations/assets are
available; full multi-character polish and production AI may take
longer.

Folders: root `00`--`17` specs; `docs/` support notes; `prompts/` phase
prompts; `cloudflare-worker/` optional backend notes; `Co-build/`
collaboration protocol.
